# PirAStack Studio : les versions

Ce dépôt ne contient que l'installateur de la dernière version de PirAStack Studio et sa page de version (`latest.json`), lue par le Studio pour se mettre à jour en un clic. **Aucun code.**

- Chaque version est signée : le Studio refuse une version dont la signature ne correspond pas.
- Le Studio ne s'ouvre qu'avec une clé personnelle, donnée par son auteur.
